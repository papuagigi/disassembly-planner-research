# Collaboration rules

Read CLAUDE.md and disassembly_repair_v7/STATUS.md first. Preserve every earlier study (v6 is the frozen baseline). New work goes to a separate version and a branch. Keep arm identities, the evaluated model, initial inputs, the common API and resource caps matched; record protocol changes (see disassembly_repair_v7/CHANGELOG.md) before new policy outcomes. Software repairs are distinct from learned physical procedures; admit new SKILL.md only after independent validation and freeze it for B/C before evaluation. Do not seek a winning arm, retry a started first episode, or learn from held-out results. Record unknown costs, native warnings and planner failures separately. No credentials, raw archives, provider logs or PPT in commits.
