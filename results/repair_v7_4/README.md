# v7.4 공개 스냅샷

2026-10-21에 완료된 기존 실행 기록을 2026-11-10에 공개했습니다. Planner는 v7.3과 같고, 평가 데이터와 반복 횟수가 달라졌습니다. 새 모델 호출, 새 분해 에피소드, 독립 재생 검증은 이번 공개 과정에서 실행하지 않았습니다.

## 결과와 범위

- 처음 보는 부품 5·6·7개짜리 CAD 각 4종, 총 12종을 평가했습니다. 각 조건을 같은 CAD에서 3회 반복했습니다.
- 1차 A, B(S5), C(S5), 2차 B(S5 + 조립체별 SKILL.md), C(S5 + 조립체별 SKILL.md)가 각각 36/36, 총 180/180회 기록상 목표에 도달했습니다. 목표는 고정 부품 하나를 제외한 나머지 부품의 안정적인 제거입니다.
- 범용 SKILL.md S5는 v7.3 개발 검증에서 불승인됐습니다. 이 사실을 유지한 상태에서 사용자가 v7.4의 bank를 S5로 선택했고, 실행 전에 고정했습니다.
- 조립체별 SKILL.md는 각 CAD의 1차 반복 1회차 A·B·C 기록으로 작성됐습니다. 2차 시도는 같은 조립체의 경험을 재사용하는 평가이며 새로운 CAD에 대한 일반화 평가로 세지 않습니다.
- 36회에는 같은 CAD의 반복이 포함됩니다. 서로 다른 CAD 36종이나 180종에 대한 검증으로 해석하지 않습니다. 선정에는 기존 형상·초기 물리·P2 참조 경로 기준을 적용했으며, 참조 경로는 planner에게 제공하지 않았습니다.
- 부품 10개 이상에 대한 성능은 이 실험으로 판단할 수 없습니다.

## 검증 상태

**전체 180회에 대한 독립 재생 검증은 미완료입니다.** 2026-10-21에 사용자의 요청으로 중단됐으며, `summary_v74.json`의 `replay`는 `null`입니다. 2026-10-23 정리 검증에서 일부 기록을 재생한 사실도 전체 180회 검증의 대체물이 아닙니다.

2026-11-10 공개 준비에서 확인한 것은 다음과 같습니다.

- 저장된 180개 에피소드의 성공 여부를 원본 결과·지표와 대조했습니다.
- 실행별 CSV의 검사 수, 실패 검사 수, 필요 제거 수, 호출 수, 토큰 수를 저장 지표와 대조했습니다.
- 기존 amendment를 반영한 고정 파일 21개의 해시가 일치했습니다.
- 고정 기록이 지정한 planner 모듈 13개가 v7.3과 바이트 단위로 같았습니다.

이는 저장 기록과 공개 스냅샷의 무결성 확인입니다. 새로운 물리 실행이나 독립 재생 결과를 의미하지 않습니다.

## 포함한 파일

- [`../../disassembly_repair_v7_4/`](../../disassembly_repair_v7_4/): 기존 코드·상태·계획. 실행 당시 원본을 보존하고 로컬 절대경로만 치환했습니다.
- [`RESULT_TABLES.md`](RESULT_TABLES.md), [`evaluation_runs.csv`](evaluation_runs.csv), [`summary_v74.json`](summary_v74.json): 기존 집계. 결과표에서 잘못 출력된 Markdown 구분선 한 곳만 공개 사본에서 바로잡았으며 수치는 바꾸지 않았습니다.
- [`memory/`](memory/): 범용·조립체별 SKILL.md와 bank manifest.
- [`records/protocol/`](records/protocol/): 후보 순서, 선정 결과, 고정 기록, amendment.
- [`records/evaluation/`](records/evaluation/): 완료 표시와 180회 실행별 요약 지표.
- [`records/note_writer/`](records/note_writer/): 조립체별 SKILL.md 작성 요약과 사용량. Provider 원문은 포함하지 않습니다.

원본 CAD, 변환 case·mesh, raw episode 결과·trace, provider 프롬프트·응답·호출 로그, 환경·인증 정보는 포함하지 않습니다. 기존 `disassembly_repair_v7.publish`의 allowlist 복사·크기 제한·secret 검사·경로 치환 함수를 사용했습니다.

이 저장소는 코드와 요약 근거의 공개 스냅샷입니다. 원래 작업 공간의 데이터·출력·SKILL.md 경로를 보존한 코드이므로, 저장소만 clone해서 원본 평가를 바로 재실행할 수 있다는 뜻은 아닙니다. 고정 기록의 해시는 원본 파일 기준이며 경로 치환된 공개 사본의 해시와 다를 수 있습니다.
