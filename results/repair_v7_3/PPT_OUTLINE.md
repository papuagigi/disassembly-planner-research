# 발표 자료 구성안 (논문식 흐름; 결과는 v7.3 최종 단계만)

사용자 지시(2026-10-21): 동기 → 목표·개요 → disassembly planner란 → A/B/C 구조 → 실험 환경 → (최종 단계) 실험 결과 → 시사점·현장 적용 → 한계.
이전 버전의 기록은 결과로 나열하지 않고, 동기와 한계의 근거로만 씁니다. 숫자는 원본 기록에서 확인한 값만 씁니다.

## 1. 연구 동기
- **문제의식:** 분해 계획은 조립체마다 새로 풀어야 합니다. LLM 기반 planner는 같은 실수를 반복했습니다. 예를 들어 이전 실험에서 생성 코드가 같은 거절 동작을 2,992번 다시 요청했고, 같은 부품의 다른 방향을 고르게 반복 시도했습니다(수용률 4~23%).
- **질문:** 실제 분해 실패에서 배운 해결 절차를 사람이 읽을 수 있는 문서(SKILL.md)로 남기면, 다음 분해가 더 잘 되는가?
- **배경:** ASPIRE(에이전트가 스킬을 발견·재사용), ASAP(물리적 실현 가능성을 고려한 조립 순서 계획).

## 2. 목표와 개요
- **목표:** 실패에서 배운 절차를 SKILL.md로 저장하고, 같은 조립체나 다른 조립체를 다시 분해할 때 그 경험을 활용해 더 잘하는 disassembly planner.
- **두 가지 기억:**
  - 일반 SKILL.md: 여러 개발 조립체의 실패 통계에서 만든 일반 절차
  - 조립체 노트: 한 조립체의 이전 시도에서 만든 전용 기억
- **학습 사이클:** 실패 기록 → 근거 통계 → LLM이 SKILL.md 작성 → 모델 없이 실제 물리에서 검사 → 개발 검증 → 고정 평가. 모델 가중치는 바꾸지 않습니다.

## 3. Disassembly planner란
- **입력:** CAD 조립체(부품 메시·자세, 고정 부품 1개)
- **행동:** (부품, 6개 방향 라벨 중 하나)를 직선으로 빼냄
- **판정:**
  1) 원본 메시 기반 경로 충돌 검사
  2) 남은 부품의 MuJoCo 안정성 1.5초 확인(중력 −9.81, 마찰 0.5)
- **목표:** 고정 부품 하나만 남을 때까지 전부 제거. 순서와 방향이 맞아야 하고, 잘못 빼면 남은 구조가 무너집니다.
- **난점:** 막힘은 상태에 따라 달라집니다(조건부 막힘). 탐색 공간이 크고 물리 검사 비용이 큽니다(거절 약 2초, 불안정 판정 약 20초).

## 4. A/B/C 구조 (같은 모델·API·예산)
- **A:** LLM이 Python 탐색 프로그램을 생성하고 실행합니다. 문서는 없습니다.
- **B:** A와 같은 방식이지만 SKILL.md를 읽고 코드를 작성합니다. 같은 조립체 노트가 있으면 기록된 순서를 먼저 시도합니다.
- **C:** 조건부 막힘 그래프와 고정 DFS를 host가 실행하고, LLM은 후보 동작의 순위만 정합니다. B와 같은 SKILL.md를 씁니다.
- **공통 API:** 상태별 탐색 기록(ledger), 막다른 상태 차단, 상태 checkpoint/복원, 같은 상태 반복 거절 캐시.

## 5. 실험 환경
- **평가 모델:** gpt-6-luna(low). 에피소드 예산은 호출 8 / 물리 검사 240 / 900초 / 8 GiB.
- **CAD:** 공식 ASAP 제품
  - 개발용(SKILL.md 작성 5개, 검증 4개)
  - 평가용 새 CAD(이전에 한 번도 열지 않음, 선정 규칙을 추출 전에 고정, 참조 경로는 선정에만 쓰고 planner에게 주지 않음)
- **평가 절차:** 실행 전 고정, 한 번에 한 에피소드, 재실행 없음, 모든 결과 보고, 독립 재생 검증.
- **엔진 개선:** 물리 계산 속도 개선(판정 동일, 기존 61개 에피소드 재생으로 확인), 형식 위반·도구 호출 시 재요청.

## 6. 실험 결과 (v7.3 — 평가 후 작성)
- 처음 보는 CAD 1차 시도: A vs B(S5) vs C(S5). 성공률, 검사 수, 시간, 토큰.
- 같은 CAD 2차 시도: B·C + 노트 vs 노트 없는 B·C vs A.
- 개발 검증 결과와 S5 승인 판정.

## 7. 시사점과 현장 적용 (결과 확인 후 확정)
- 재제조·정비·폐기 분해 현장에서 같은 제품군이 반복되면 조립체 노트가 누적 효과를 낼 수 있습니다(결과에 따라).
- 사람이 읽을 수 있는 SKILL.md는 검토·수정·감사가 가능한 지식입니다.
- 일반 절차는 가정을 먼저 확인하는 조건부 형태여야 합니다.

## 8. 한계 (근거 있는 것만)
- **일반 SKILL.md:** 고정된 사전 가정이 조립체에 따라 도움 또는 해가 됐습니다. 위 축 CAD에서는 효과가 있었고, 옆 축 CAD에서는 실패했습니다.
- **물리 단순화:** 6방향 직선 이동만 허용하고, 로봇·그리퍼·힘 기반 분해는 없습니다. 일부 CAD는 이 모델에서 완전 분해가 불가능했습니다.
- **인프라:** 모델의 도구 호출, 메모리 상한, 시간 예산 대비 느린 물리 검사.
- **표본:** CAD 수가 적고 조건당 반복이 적습니다. 같은 조건의 A도 검사 수가 48~225회로 흔들렸습니다.
- **평가용 CAD 수급:** 실현 가능한 새 CAD가 드뭅니다(v7 선정 수확률 3/75).
