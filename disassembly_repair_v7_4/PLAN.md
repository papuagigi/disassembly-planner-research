# v7.4 계획: 쉬운 CAD 반복 평가로 보는 신뢰성

사용자 지시(2026-10-21): 분해 단계가 적은 CAD 여러 개로 반복 테스트해 신뢰성을 평가한다. 성공률이 높으면 LLM이 쓴 토큰과 시간 같은 효율 지표가 주요 지표가 된다.

## 무엇을 바꾸고 무엇을 고정하나
- **planner는 바꾸지 않습니다.** A·B·C 코드, 계약, 예산(호출 8, 검사 240, 900초, 8 GiB), 물리 P2, 모델 gpt-6-luna/low는 v7.3과 같습니다.
  - v7.4의 planner 모듈은 v7.3 파일의 바이트 동일 복사본이고, 고정 단계에서 이를 다시 확인합니다.
  - 바뀐 것은 출력 경로 7줄뿐입니다.
- **바뀌는 것은 평가 데이터와 반복 횟수입니다.**
  - 데이터: 한 번도 쓰지 않은 5~7개 부품 CAD 12개(필요한 제거 4~6개).
  - 반복: 조건마다 3회.
- 범용 SKILL.md는 실행 전에 하나로 고정합니다(아래 "결정이 필요한 것").

## CAD 선정 (모델 없음, `selection74.py`)
- **후보:** ASAP 학습 세트 중 이 작업 공간에서 한 번도 열지 않은 제품입니다(v7.3이 심사한 92개 포함 866개 제외).
  - 5개 부품 202개, 6개 104개, 7개 89개입니다.
- **순서:** 부품 수별로 ID를 정렬한 뒤 고정 시드(20261021)로 섞고, 5·6·7을 번갈아 처리합니다.
  - v7.3처럼 파일 크기순으로 고르지 않는 것은, 단순한 메시만 골라지는 편향을 피하기 위해서입니다.
- **통과 기준 (v7.3과 같음):** 형상 검사, 충돌 메시 준비, 초기 물리 안정, MuJoCo 로그 이상 없음, 중복 형상 아님, 그리고 P2 기준 참조 탐색으로 완전 분해 경로가 존재해야 합니다.
  - 참조 경로는 선정에만 쓰고 planner에게 주지 않습니다.
- **목표:** 부품 수별 4개씩 12개. 다 찼으면 남은 후보는 열지 않습니다.

## 실행 순서 (`campaign74.py`, CAD당 15 에피소드, 총 180)
1. **1차 시도:** A(SKILL.md 없음), B(범용), C(범용)를 각 3회 돌립니다. 순서는 CAD와 반복마다 돌려 시간대 영향을 고르게 합니다.
2. **조립체별 SKILL.md:** 1차 반복 1회차의 A·B·C 기록 3개로 v7.3과 같은 방식으로 한 번 작성합니다.
3. **2차 시도:** B(범용 + 조립체별), C(범용 + 조립체별)를 각 3회 돌립니다.
4. **규칙:** 한 번에 하나씩, 컴퓨터가 조용할 때만 실행합니다. 시작한 에피소드는 다시 돌리지 않고, 모든 결과를 보고합니다.

## 미리 정하는 지표
- **신뢰성:** 조건별 성공률(36회)과 Wilson 95% 구간, 3회 모두 성공한 CAD 수.
- **효율 (성공률과 상관없이 보고, 성공률이 같으면 주 비교):**
  - **낭비 검사 수** = 실제 검사 수 − 필요한 제거 수(성공 에피소드의 중앙값·사분위·최댓값). 모델이나 컴퓨터 부하에 흔들리지 않는 탐색 효율 지표입니다.
  - **토큰·모델 호출 수:** 에피소드당 비용입니다. C는 순위 호출 때문에 구조적으로 토큰이 많으므로, 같은 구조 안의 비교(1차 대 2차)가 더 공정합니다.
  - **시간:** 전체 시간을 모델 시간(호출별 응답 시간의 합)과 나머지(물리 판정·host)로 나눕니다. 쉬운 CAD에서는 모델 시간이 대부분일 수 있습니다.
- **흔들림:** CAD별로 같은 조건 3회의 차이를 봅니다.
- **비교 (CAD별로 짝지어 기술):**
  - A 대 B: 범용 SKILL.md의 효과
  - B 대 C: 역할 분담의 효과
  - 같은 조건의 1차 대 2차: 조립체별 SKILL.md의 효과
  - 12쌍 Wilcoxon 검정은 보조로만 씁니다.
- **인프라 실패:** provider 오류나 엔진 자원 오류로 검사 0회에 끝난 에피소드는 분모·분자에서 빼고 목록으로 공개합니다.

## 비용 추정 (v7.3 실측 기준, 상한 쪽 추정)
- **토큰:** 약 1,000만입니다.
  - v7.3의 에피소드당 평균은 1차 A 2.5만, B·S5 4.9만, C·S5 9.9만, 2차 B 4.5만, C 5.4만이었습니다.
  - 쉬운 CAD는 턴 수가 적어 이보다 적을 수 있습니다.
- **시간:** 에피소드 실행 약 3시간이고, CAD 선정은 2~5시간(통과율에 따라)입니다.
  - v7.3에서 9개 부품 CAD의 에피소드 중앙값은 22~65초였습니다.

## 결정이 필요한 것 (실행 전)
- **범용 SKILL.md:**
  - **S5(최신, v7.3 개발 검증 불승인):** 발표 자료의 기준과 같습니다.
  - **S3(마지막 승인본):** 사전 규칙상 승인된 버전입니다.
  - 둘 다 돌리면 B·C 1차가 72회 늘어 252 에피소드가 됩니다.
- **실행 승인:** 고정(freeze) 후 LLM 에피소드를 시작하려면 사용자 승인이 필요합니다.

## 예상되는 한계
- 쉬운 CAD에서는 A도 대부분 성공할 가능성이 큽니다(천장 효과). 그러면 성공률로는 조건 차이가 거의 안 보이고, 결론은 효율·흔들림 지표에서 나옵니다.
- 토큰과 시간은 구조(C의 순위 호출)와 컴퓨터 상태의 영향을 받으므로, 낭비 검사 수와 함께 읽어야 합니다.
